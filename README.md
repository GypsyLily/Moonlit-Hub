# Moonlit Hub

Public presentation and download site for the Moonlit software ecosystem.

This repository contains only material intentionally approved for public sharing. Private product source, Moonlit Atlas internal documentation, recovery archives, secrets, account data, and unapproved development binaries do not belong here.

## Site

The site is a lightweight static GitHub Pages site using index.html, styles.css, and script.js with no backend or build step.

## Downloads

Approved end-user builds should be published through GitHub Releases rather than committed into the repository. A product with no approved public build should remain marked as unavailable.

## GitHub Pages

Enable Settings > Pages > Deploy from a branch, then select main and /(root).

Expected address: https://gypsylily.github.io/Moonlit-Hub/
